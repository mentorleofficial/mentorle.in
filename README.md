# mentorle.in

The public, mentee-facing Mentorle website. Built with Next.js 16, React 19, TypeScript, Tailwind CSS v4, GSAP and Lenis.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

## Docs

- [CLAUDE.md](CLAUDE.md): project overview, structure, standing rules and the workflow for building a new page
- [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md): colours, typography, spacing, components, motion and responsive rules
- [docs/SPEC-VS-DESIGN.md](docs/SPEC-VS-DESIGN.md): open differences between the product specs and the Figma designs
